Simulink block

Application Arguments

GenericTarget / Target Stats / Application Arguments

Reads all command-line arguments that were passed to the target application at start-up; the first argument is the executable name. The maximum number of characters per argument and the maximum number of arguments are configured via the block mask. During simulation, this block has no effect.

Output Ports

args

An N-by-M matrix of the argument characters, where N is the maximum number of characters per argument and M the maximum number of arguments.

Data Type: uint8

numCharacters

A vector of length M; each element gives the actual number of characters of the corresponding argument in the args output matrix.

Data Type: uint32

numArguments

A scalar value with the actual number of arguments available in the args output matrix.

Data Type: uint32

Block Parameters

The following table shows all block parameters.

Parameter NameDescription
maxNumCharsPerArgumentMaximum number of characters per argument.
maxNumArgumentsMaximum number of arguments.
SampleTimeSample time of the block.
