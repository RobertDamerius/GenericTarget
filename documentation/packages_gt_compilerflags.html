MATLAB class

GT.CompilerFlags

This class represents additional compiler and linker flags for the GT.GenericTarget class. The properties are applied when the Makefile is generated during deployment.

Construction

flags = GT.CompilerFlags() creates a CompilerFlags object with default properties.

Properties

The properties of this class are summarized in the following table; detailed descriptions follow.

PropertyData TypeDefault ValueDescription
DEBUG_MODElogicalfalsetrue if DEBUG mode is to be enabled when compiling the target software, false otherwise.
LD_LIBScell array{}Additional libraries to link against.
CC_SYMBOLScell array{}Additional symbols to be set when compiling.
CC_FLAGScell array{}Additional flags to be set when compiling C source files.
CPP_FLAGScell array{}Additional flags to be set when compiling C++ source files.
LD_FLAGScell array{}Additional flags to be set when linking the application.
INCLUDE_PATHScell array{}Additional include paths to be set when compiling source files.
LIBRARY_PATHScell array{}Additional library paths to be set when linking the application.

DEBUG_MODE

This flag specifies whether the target application is compiled in debug mode. In debug mode, compiler optimizations are disabled, the symbol DEBUG is defined, and the compiler flag -ggdb is added. The application then no longer requires root privileges and does not terminate if thread priorities cannot be set. If this flag is false, the optimization level -O3 is used and the debug symbols are not included in the application.

LD_LIBS

Additional libraries that are linked into the application. The complete library list used by the linker is: 

-lstdc++ -lstdc++fs -lpthread -latomic $TARGET_MAKEFILE_LD_LIBS$

in which the placeholder $TARGET_MAKEFILE_LD_LIBS$ is replaced by the additional libraries.

CC_SYMBOLS

Additional preprocessor symbols that are defined when compiling the target application. The complete symbol list is:

-DGENERIC_TARGET_IMPLEMENTATION $TARGET_MAKEFILE_CC_SYMBOLS$

in which the placeholder $TARGET_MAKEFILE_CC_SYMBOLS$ is replaced by the additional symbols.

C/C++ macros

The GENERIC_TARGET_IMPLEMENTATION macro can be used to guard areas of C/C++ code that are only compiled when the flag -DGENERIC_TARGET_IMPLEMENTATION is set.

CC_FLAGS

Additional compiler flags that are applied when compiling C source files. The complete flag set is: 

-Wall -Wextra -Wno-format-security -mtune=native $TARGET_MAKEFILE_CC_FLAGS$

in which the placeholder $TARGET_MAKEFILE_CC_FLAGS$ is replaced by the additional flags.

CPP_FLAGS

Additional compiler flags that are applied when compiling C++ source files. The complete flag set is: 

-std=c++20 -Wall -Wextra -Wno-format-security -mtune=native $TARGET_MAKEFILE_CPP_FLAGS$

in which the placeholder $TARGET_MAKEFILE_CPP_FLAGS$ is replaced by the additional flags.

LD_FLAGS

Additional linker flags that are applied when the target application is linked. The complete flag set is: 

-Wall -Wextra -Wno-format-security -mtune=native $TARGET_MAKEFILE_LD_FLAGS$

in which the placeholder $TARGET_MAKEFILE_LD_FLAGS$ is replaced by the additional linker flags.

INCLUDE_PATHS

Additional include paths that are added when compiling source files. The complete include list is: 

-I/usr/local/include $TARGET_MAKEFILE_INCLUDE_PATHS$

in which the placeholder $TARGET_MAKEFILE_INCLUDE_PATHS$ is replaced by the additional paths.

LIBRARY_PATHS

Additional library search paths that are added when the target application is linked. The complete path list is: 

-L/usr/local/lib $TARGET_MAKEFILE_LIBRARY_PATHS$

in which the placeholder $TARGET_MAKEFILE_LIBRARY_PATHS$ is replaced by the additional paths.
