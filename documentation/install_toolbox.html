Install the Toolbox (MATLAB)

Installing the Generic Target Toolbox consists of adding its directories to the MATLAB path. There are two options: add the toolbox to the MATLAB path directly, or include it as a reference project in an existing MATLAB project so that it is available on the project path. In both cases, the toolbox must be located in a directory whose absolute path contains no special characters and no spaces.

Option 1 — Add to the MATLAB path

Run the installation script install.m. The script adds the necessary directories to the MATLAB path and requests to rebuild the Simulink library blocks.

Option 2 — Add to the project path

Add the project file GenericTarget.prj as a reference project to your existing MATLAB project. The toolbox directories then become available on the project path of that project.

Troubleshooting (Linux) — GLIBCXX conflict

On Linux-based host systems, MATLAB bundles its own GCC runtime libraries to ensure compatibility on distributions that lack them. Building the Generic Target driver blocks, however, links against the system libstdc++. A version mismatch between the bundled and the system library can cause a GLIBCXX conflict error when running Simulink models.

Solution: Navigate to the MATLAB installation directory MATLAB/sys/os/glnxa64/ and rename or delete all files that start with libstdc++. Restart MATLAB afterwards to apply the changes.

Toolbox Directory Structure

The Generic Target Toolbox directory is structured as follows:

Directory / FileDescription
coreSource code and template files for the Generic Target Core.
documentationThis HTML-based documentation.
libraryThe "GenericTarget" Simulink library, including S-functions and the mex binaries of the driver blocks.
packagesThe MATLAB package GT.
resourcesProject definition files for the MATLAB project.
GenericTarget.prjThe MATLAB project file.
install.mMATLAB script that installs the Generic Target Toolbox and saves it to the MATLAB path.
readme.htmlEntry point of the HTML-based documentation; open this file in a browser to view it.

Rebuild Library Blocks (recommended)

The toolbox is shipped with prebuilt library blocks for Windows and Ubuntu. It is recommended to build the Simulink driver blocks for your own platform. Run GT.BuildDrivers() from the MATLAB command window to generate all necessary driver files. A prerequisite is that a C/C++ compiler is configured in MATLAB (mex -setup).

Simulink support

Run GT.BuildDrivers() to compile all driver blocks. Most of the blocks also work during simulation in Simulink; the following table summarizes which blocks are supported and their behavior during simulation.

Building the driver blocks has been tested with the gcc toolchain (Linux) and MSYS2/MinGW64 (Windows). The GCC version must be 13 or newer.

Uninstall

To uninstall the toolbox, remove its directories from the MATLAB path again (for example, with removepath). The install.m script adds exactly three folders to the MATLAB path: library, library/drivers, and packages. If the toolbox was added as a reference project instead, simply detach the reference project in the project settings.
