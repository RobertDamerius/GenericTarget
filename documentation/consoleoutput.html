Console Output

The console output provides a time-stamped log of the target application: informational events about the system and the application, as well as warnings and error messages. Each log message carries an absolute UTC timestamp.

Log Format

The output consists of a header marking the start of the application, descriptive information about the system and the application, the time-stamped log messages, and a footer marking the stop of the application. Each log message is prefixed with an absolute UTC timestamp and a severity level: [INFO], [WARNING], or [ERROR]. The log is written to the standard error stream. When the application is started with GT.GenericTarget.Start, this stream is redirected to out.txt in the target software directory.
