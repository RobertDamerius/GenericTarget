Simulink block

Read Thermal Zones

GenericTarget / Target Stats / Read Thermal Zones

Reads the temperature values of the thermal zones exposed by the Linux kernel under /sys/class/thermal/thermal_zone[i]/temp, where [i] is the index of the thermal zone. The maximum number of thermal zones to read is specified via the mask parameter and determines the output dimension. If a thermal zone does not exist, NaN is returned for the corresponding index. During simulation, this block works only on Linux-based hosts.

Output Ports

temperatures

A vector of length N containing the temperatures of the N thermal zones in degrees Celsius. If a thermal zone is unavailable or contains no temperature information, NaN is returned for that zone.

Data Type: double

Block Parameters

The following table shows all block parameters.

Parameter NameDescription
maxNumThermalZonesMaximum number of thermal zones to read; this value sets the output dimension.
SampleTimeSample time of the block.
