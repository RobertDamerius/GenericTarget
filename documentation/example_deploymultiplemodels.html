Deploy Multiple Models

If multiple models are to be deployed on the same target computer, a separate application directory must be defined for each model. If the applications are also to run in parallel, the target socket name of each application must be system-wide unique.

In this example, two applications run on the same target computer. The Simulink models Model1 and Model2 are deployed into the directories Software1 and Software2 of the home directory, respectively, and are given the distinct executable names Application1 and Application2. Each model is deployed with its own deployment script.

Script 1: Deployment of Model1

% Create a target object
username = 'user';
address  = '192.168.0.100';
target   = GT.GenericTarget(username, address);

% Update properties
target.targetSocketName        = '/run/generic-target/application1.lock';
target.targetSoftwareDirectory = '~/Software1/';
target.targetProductName       = 'Application1';

% Deploy the model
target.Deploy('Model1');

Script 2: Deployment of Model2

% Create a target object
username = 'user';
address  = '192.168.0.100';
target   = GT.GenericTarget(username, address);

% Update properties
target.targetSocketName        = '/run/generic-target/application2.lock';
target.targetSoftwareDirectory = '~/Software2/';
target.targetProductName       = 'Application2';

% Deploy the model
target.Deploy('Model2');

Warning — Starting multiple real-time applications

Applications running in parallel are not synchronized in time: each application runs with its own timer, and the timer events of one application are not aligned with the timer events of the others.
