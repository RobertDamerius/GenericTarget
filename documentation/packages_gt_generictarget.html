MATLAB class

GT.GenericTarget

This class is the main interface to the target computer and the Generic Target application running on it. Several properties can be modified to adjust the behavior of the application and the deployment process. The public object functions are listed below.

Construction

target = GT.GenericTarget() creates a target object with all default property values.

target = GT.GenericTarget(targetUsername, targetAddress) creates a target object and sets the properties targetUsername and targetAddress; all other properties keep their default values.

Properties

The properties of this class are summarized in the following table; detailed descriptions follow.

connectTimeoutuint323Connection timeout in seconds for SSH and SCP.
targetAddresschar array''IP address (or host name) of the target computer.
targetUsernamechar array''User name of the target computer, used to log in via SSH/SCP.

targetProductNamechar array'GenericTarget'File name of the executable on the target.
targetSocketNamechar array'/run/generic-target/app.lock'A system-wide unique socket name to be set for an abstract UNIX socket (without a leading null byte).
targetBitmaskCPUCoreschar array''Hexadecimal bitmask selecting the CPU cores the application is pinned to. If the string is empty, all cores are available.
applicationArgumentschar array''A string representing additional arguments passed to the application during a Start call.
customCodecell array{}Cell array of files or directories containing custom code to be uploaded along with the generated code.
additionalCompilerFlagsGT.CompilerFlagsGT.CompilerFlags()An object of the GT.CompilerFlags class with additional compiler flags applied during Makefile generation.

portSSH

Commands are executed on the target via SSH; file transfer is done via SCP. Both protocols use port 22 by default. This property adjusts the port, for example when the target computer is behind a router and port 22 cannot or should not be forwarded.

connectTimeout

All communication with the target is done via SCP and SSH. If the target is not reachable, the attempt to establish a connection is aborted after this timeout (in seconds) so that the MATLAB functions do not block indefinitely.

targetAddress

The address of the target computer, as an IP address string or host name. It is used to establish the network connection for deployment and control.

targetUsername

The user name of the target computer. It is used to establish the SSH/SCP connection for deployment and control.

targetSoftwareDirectory

The directory on the target computer into which the real-time application is deployed. The directory must be located inside the home directory. If several target applications run simultaneously on the target, each must be deployed into a separate directory.

targetProductName

The name of the executable on the target. The name must be a valid MATLAB variable name (see isvarname).

targetSocketName

When the application is started, it binds to an abstract UNIX socket with the name set by this property. Binding this socket acts as a lock that ensures the application runs only once. When the application terminates, the socket is released. If several target applications are to run simultaneously on the same computer, each application must use a distinct socket name.

targetBitmaskCPUCores

Optionally, the target application can be pinned to specific CPU cores. The bitmask is given as a hexadecimal string; the application may run only on the cores whose bit is set to 1. For example, a bitmask of '0x0f' restricts the application to cores 0 to 3. If the string is empty, all CPU cores are available.

applicationArguments

Additional command-line arguments that are appended to the start command during a Start call.

customCode

Additional source code to include in the target software. The given files and directories are uploaded along with the generated code and compiled on the target together with the Generic Target Core.

additionalCompilerFlags

An object of the GT.CompilerFlags class with additional compiler flags that are applied when the Makefile is generated on the target.

Object Functions

The class provides the following public member functions for interacting with the target application and the target computer:

  • Deploy — deploys a Simulink model to a target
  • DeployGeneratedCode — deploys the generated code to a target
  • DeployToHost — deploys a Simulink model to the host
  • GenerateCode — generates the code from a Simulink model
  • Start — starts the real-time application on the target
  • Stop — stops the real-time application on the target
  • Reboot — reboots the target computer
  • Shutdown — shuts down the target computer
  • ShowPID — shows the process ID of the real-time application on the target
  • ShowIsolatedCPUCores — shows the isolated CPU cores on the target computer
  • DownloadDataDirectory — downloads a data recording directory from the target
  • DownloadAllData — downloads all data recording directories from the target
  • DeleteAllData — deletes all data recording directories from the target
  • GetTargetDataDirectoryName — returns the directory name of the data recording directory on the target
  • RunCommandOnTarget — runs a command on the target

Deploy

commands = target.Deploy(modelName)

target is the GT.GenericTarget object.

Deploys the target application. The code for the Simulink model is generated, and a Simulink interface class is generated from the code information of the Simulink code generation process. The source code is compressed and transferred to the target via SCP; an SSH connection is then used to unpack the archive and build the target application on the target computer. The application is not started at the end of this process — run Start to start it.

Input Arguments

  • modelName — The name of the Simulink model to be deployed (excluding directory and file extension).

Output Arguments

  • commands — The commands that were executed on the host.

DeployGeneratedCode

commands = target.DeployGeneratedCode(zipFileName)

target is the GT.GenericTarget object.

Deploys previously generated code to the target computer. The code must have been generated with the GenerateCode method. The archive is transferred to the target via SCP; an SSH connection is then used to unpack it and build the target application. The application is not started at the end of this process — run Start to start it.

Input Arguments

  • zipFileName — The name of the zip file that contains the code generated with the GenerateCode member function. The file extension must be '.zip'.

Output Arguments

  • commands — The commands that were executed on the host.

DeployToHost

target.DeployToHost(modelName, directory)

target is the GT.GenericTarget object.

Deploys the target application to a directory on the host machine. The complete Generic Target framework, including the generated code, is written into the specified directory. The software is not compiled as part of this operation.

Input Arguments

  • modelName — The name of the Simulink model to be deployed (excluding directory and file extension).
  • directory — Optional name of the directory where the generated target application code is saved (an absolute path is recommended). If no directory is specified, the current working directory (pwd) is used.

GenerateCode

target.GenerateCode(zipFileName, modelName)

target is the GT.GenericTarget object.

Generates the code for the Simulink model and the Simulink interface class, which is derived from the code information of the Simulink code generation process. The complete source code is compressed into a .zip archive.

Input Arguments

  • zipFileName — The name of the zip file where to store the generated code. The file extension must be '.zip'.
  • modelName — The name of the Simulink model to be code-generated (excluding directory and file extension). The value is forwarded to the slbuild() command.

Start

commands = target.Start()

target is the GT.GenericTarget object.

Starts the target application over an SSH connection. If the application is already running, the call has no effect. The application's console output is redirected to out.txt in the target software directory.

Output Arguments

  • commands — The commands that were executed on the host.

Stop

commands = target.Stop()

target is the GT.GenericTarget object.

Stops the target application over an SSH connection. If no application is running, the call has no effect.

Output Arguments

  • commands — The commands that were executed on the host.

Reboot

commands = target.Reboot()

target is the GT.GenericTarget object.

Reboots the target computer. The reboot command is executed over an SSH connection.

Output Arguments

  • commands — The commands that were executed on the host.

Shutdown

commands = target.Shutdown()

target is the GT.GenericTarget object.

Shuts down the target computer. The shutdown command is executed over an SSH connection.

Output Arguments

  • commands — The commands that were executed on the host.

ShowPID

commands = target.ShowPID()

target is the GT.GenericTarget object.

Prints the process IDs of all processes on the target whose name matches targetProductName. This can be used to check whether the application is running; if no process matches, the output is empty.

Output Arguments

  • commands — The commands that were executed on the host.

ShowIsolatedCPUCores

commands = target.ShowIsolatedCPUCores()

target is the GT.GenericTarget object.

Prints the isolated CPU cores on the target (see the isolcpus option in hardware tuning). If no CPU cores are isolated, the output is empty.

Output Arguments

  • commands — The commands that were executed on the host.

DownloadDataDirectory

commands = target.DownloadDataDirectory(hostDirectory, targetDataDirectory)

target is the GT.GenericTarget object.

Downloads a recorded data directory from the target and writes it to hostDirectory.

Input Arguments

  • hostDirectory — The destination directory on the host where the downloaded data is written (an absolute path is recommended). If the directory does not exist, it is created. If this argument is omitted, the current working directory is used.
  • targetDataDirectory — Optional name of the data directory on the target to be downloaded, e.g., "20261109_123456789". If this argument is omitted, all data directories on the target are listed and the user selects one interactively.

Output Arguments

  • commands — The commands that were executed on the host.

DownloadAllData

commands = target.DownloadAllData(hostDirectory)

target is the GT.GenericTarget object.

Downloads all recorded data directories from the target and writes them to hostDirectory.

Input Arguments

  • hostDirectory — The destination directory on the host where the downloaded data is written (an absolute path is recommended). If the directory does not exist, it is created. If this argument is omitted, the current working directory is used.

Output Arguments

  • commands — The commands that were executed on the host.

DeleteAllData

commands = target.DeleteAllData()

target is the GT.GenericTarget object.

Deletes all recorded data on the target. If a target application is running, it is stopped first.

Output Arguments

  • commands — The commands that were executed on the host.

GetTargetDataDirectoryName

dataDirectory = target.GetTargetDataDirectoryName()

target is the GT.GenericTarget object.

Returns the absolute path of the data directory on the target.

Output Arguments

  • dataDirectory — The absolute data directory on the target (the path ends with a separator '/').

RunCommandOnTarget

[commands, cmdout] = target.RunCommandOnTarget(cmd)

target is the GT.GenericTarget object.

Runs an arbitrary command on the target computer via SSH.

Input Arguments

  • cmd — The command string to be executed on the target computer, e.g., 'ls'.

Output Arguments

  • commands — The commands that were executed on the host.
  • cmdout — The output returned by the command on the target.
